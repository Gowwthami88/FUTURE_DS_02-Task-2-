# FUTURE_DS_02-Task-2-
Power BI dashboard analyzing customer retention, churn behavior, engagement patterns, and subscription trends using Netflix user data.
Netflix Customer Retention & Churn Analysis
Project Overview

This project analyzes customer retention and churn behavior using Netflix subscription data. The dashboard identifies factors influencing churn, user engagement trends, and customer satisfaction patterns.

Tools Used:
  Power BI
  DAX
  Excel
  Data Visualization
Dashboard Features
  Executive Overview
    Total Customers
    Churn Rate
    Average Watch Hours
    Customer Satisfaction
    Subscription Analysis
    Retention Analysis
    Satisfaction Score vs Churn
    Watch Hours vs Engagement
    Subscription Length Analysis
    Age Group Analysis
    Customer Behavior Insights
    Genre Preferences
    Device Usage
    Support Queries Analysis
    Promotional Offers Analysis
Key Insights:
  Premium users show higher retention rates.
  Delayed payments correlate with increased churn.
  High engagement users remain subscribed longer.
  Low satisfaction customers are more likely to churn.
  Customers using multiple profiles show stronger retention.
Recommendations:
  Promote annual subscription plans.
  Improve customer support response times.
  Offer personalized content recommendations.
  Reward long-term loyal customers.
  Reduce payment failures.
